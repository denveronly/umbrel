ЗАВАНТАЖЕННЯ АКТІВ ЗІ «СКЛАДИ» В BAS БУХГАЛТЕРІЯ 2.1 — ЧЕРЕЗ ФАЙЛ
================================================================

Що робить обробка
-----------------
Береш файл актів, вивантажений у «Склади», і обробка створює в базі BAS:
  • «Реалізація товарів і послуг» — рядки «Оренда …» і «Компенсація комунальних послуг …»;
  • «Рахунок на оплату покупцю» — ті самі суми (галочку можна зняти).
Ні мережі, ні токенів: файл можна перенести флешкою, поштою, через Telegram.
Беруться лише акти організації цієї бази (за ЄДРПОУ); готівкові орендарі у файл не потрапляють.
Документи записуються БЕЗ проведення — бухгалтер перевіряє, проводить, друкує, робить ПН.
Повторне завантаження того ж місяця документи не дублює:
  • документ ще НЕ проведений — оновлюється новими сумами;
  • документ уже ПРОВЕДЕНИЙ — не змінюється; якщо сума інша, буде попередження ⚠.

Важливо: перший раз спробуйте на КОПІЇ бази (Конфігуратор → Адміністрування → Вивантажити інформаційну базу →
потім Завантажити в нову порожню базу).

Перед першим запуском
---------------------
1. У «Склади» → Налаштування → Компанії: у компаній вказані ЄДРПОУ — такі самі, як в організаціях BAS.
2. У кожній базі BAS має бути хоча б одна «Реалізація товарів і послуг» за послуги, зроблена вручну й проведена:
   обробка копіює з неї рахунки обліку (доходів, ПДВ, розрахунків), підрозділ, тип цін.

Створення обробки (один раз, у Конфігураторі; ~10 хвилин). Конфігурацію бази НЕ змінюємо — це окремий файл.
------------------------------------------------------------------------------------------------------------
1. Запустіть BAS → виберіть базу → кнопка «Конфігуратор».
2. Файл → Новий… → «Зовнішня обробка» → ОК.
   Праворуч: Ім'я: ЗавантаженняАктівСклади, Синонім: Завантаження актів зі «Склади».
3. Вкладка «Реквізити» → кнопка «+» двічі:
     Период            — тип Дата, «Склад дати»: Дата   (ім'я саме так, з російською «и»)
     СтворюватиРахунок — тип Булево
4. Вкладка «Форми» → «+» → «Форма обробки» → Готово. Відкриється редактор форми.
5. У редакторі форми, вкладка «Реквізити» (праворуч угорі): розгорніть «Об'єкт» і перетягніть
   Период і СтворюватиРахунок у дерево елементів ліворуч.
6. Вкладка «Команди» → «+» → Ім'я: Завантажити, Заголовок: Завантажити з файлу…
   У властивості «Дія» натисніть лупу — створиться процедура. Перетягніть команду в елементи форми (ліворуч).
7. Унизу редактора форми — вкладка «Модуль». Виділіть усе (Ctrl+A) і вставте вміст файлу
   «1_Модуль_форми.bsl» повністю (замінивши те, що там було).
8. Властивості форми (двічі клацнути «Форма» у дереві елементів) → «События» → «ПриОткрытии»:
   натисніть лупу — має вказувати на процедуру ПриОткрытии з модуля (якщо створилась друга порожня — видаліть її).
9. Файл → Зберегти як… → «ЗавантаженняАктівСклади.epf» (наприклад, на робочий стіл). Конфігуратор закрийте.

Щомісяця
--------
1. «Склади» → Акти → потрібний місяць → блок «📥 Для BAS» → кнопка компанії (напр. «⤓ Регіон-АГРОбуд»)
   → скачається файл BAS_akty_2026-11_....json.
2. BAS (звичайний режим) → Файл → Відкрити… → ЗавантаженняАктівСклади.epf
   → «Завантажити з файлу…» → вибрати файл → унизу повідомлення: скільки актів і які документи створено.
3. Продажі → Реалізація товарів і послуг — перевірити, провести, надрукувати; ПН — як звичайно.

Щоб обробка була під рукою: Адміністрування → Друковані форми, звіти та обробки → Додаткові звіти та обробки →
Додати з файлу (якщо ввімкнено), або просто відкривайте файл через Файл → Відкрити.

Якщо щось не так
----------------
• «Пропущено актів … немає організації з таким ЄДРПОУ» — файл іншої компанії або ЄДРПОУ в BAS/«Склади» різні.
• Не той рахунок доходів / ПДВ у рядках — виправте в останній ручній реалізації; наступні копіюватимуть її.
• Помилка про реквізит, якого немає (назви в релізах BAS різняться) — надішліть текст помилки.
